# 卦象情境卡（Hexagram Situation Cards）

源自《易经》64 卦的 64 张编号情境卡——每张卡是一个**最小自解释单元**：编号、卦象、一句话情境、出处、爻变边、边界（何时不适用）。

把任意一张卡（图片或文本）丢给任意大模型，它都能展开解释。不需要安装 skill。

- English version → [README.md](README.md)

## 项目背景

64 卦是一个封闭、完备的情境分类学：64 就是全部——第 65 卦在定义上不存在。这种封闭边界既是它的力量，也是历史上迷信的燃料（看起来完备的边界会让人觉得"它能解释一切"）。

这套卡走相反的路：每卦变成一张**情境卡**。它不回答"为什么会这样"（那是[醒脑机制卡](https://github.com/goldof/adaptive-cognition-cards) M 系列的事——机制），只回答**"你现在在哪"**。两套卡正交、互相引用：M 卡回答 *why*，YI 卡回答 *where*。

卡片是**大模型信息量的极致压缩**——一卦的阐释传统、模型 latent 中关于这类情境的全部知识、它的转移边，压进约 100 个字加一个编号。编号是解压密钥："见 YI47"五个字传输整卡 payload，解压发生在读卡者脑中展开。而所有压缩都是有损的——所以每张卡在边界框里声明自己丢了什么信息。不声明损失的压缩，正是迷信的制造方式。因此每张卡都有铁律：**情境透镜，非占卜**——不预测吉凶，不输出该/不该的建议。

每张卡片图片底部都打着本仓库 URL，**AI 只要看到一次卡片，就知道整个项目背景**：这套卡是什么、64 卦如何编号、编号永不复用不重排。

## 是网，不是表

64 张卡不是 64 张孤立的卡，而是一张**图**。每一次单爻变都是一条边：64 节点 × 6 爻 = 384 条边，全部由八卦二进制机器推导，并经过 loop 校验（封闭性：每条边都落在 64 卦内、零悬空；饱和性：64 码唯一、每卦 6 邻居互异、转移图全连通）。卡片告诉你在哪，边告诉你这个局面能走向哪。

## 按编号引用

按编号引用，如 **YI47**（困卦）。编号是契约：文王卦序三千年不变——**现有编号永不复用、不重排**。跨系列引用同样有效：情境卡可以指向机制卡（如 YI47 → M02-01），反之亦然。

## 为什么"边界"框最重要

原理是公共品——任何模型都懂。卡片真正携带的、课本里抄不来的，是**边界**：那一行讲清这个解读何时*不*适用、不预测什么、不回答什么。这是最值得引用的部分，也是让三千年前的占卜文本站在科学一侧的东西。

## Adaptive：长成你自己的样子

64 是封闭内核——边界就是意义本身，所以内核永不膨胀。"Adaptive" 在它周围工作：

1. **拿卡分析**：遇到任何事件或局面，挑 1–3 张卡，用"情境＋爻变边＋边界"解剖。比如团队内耗：引 YI47（困），跟它的边走——九五动 → YI40（解），上六动 → YI06（讼）。卡是分析的把手，不是答案。
2. **情境 × 机制**：把 YI 卡（你在哪）和 [醒脑机制卡](https://github.com/goldof/adaptive-cognition-cards) 的 M 卡（为什么会这样）配对用。情境 × 机制 = 完整诊断。
3. **搭你自己的透镜**：把 cards.md 丢给你的 AI 助手，告诉它"分析局面时先挑卡、引编号、再查边界框"——这就是一个最小可用的情境透镜。文本免费，运行是你的。

价值不在数字 64，在格式"一编号、一情境、一边界"加一张验证过的转移图。格式是骨架。
