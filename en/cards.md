# YI · 64 Hexagram Situation Cards (text version, spec v1)

Each card: number / hexagram name & figure / one-line situation / source / yao-change edges / boundary (when it does not apply).
This series is a **situation lens, not a fortune**: it does not predict good or bad luck, and it gives no should/shouldn't advice.
Yao-change edges are machine-generated by `yi_engine.py` from binary trigram composition (11 closedness/saturation checks passed); traditional figure names (Heaven-over-Water style) likewise engine-generated. Never hand-edit.
Image versions pending the card image pipeline; each entry in cards.json carries its own image_url.
